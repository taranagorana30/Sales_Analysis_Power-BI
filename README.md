# Sales Analysis Dashboard

## Project Overview
This project is an interactive Sales Analysis Dashboard created using Power BI.

## Tools Used
- Power BI
- DAX
- Microsoft Excel

## Dataset
The dataset contains sales information including:
- Category
- Customer Name
- Discount
- Order Date
- Order ID
- Payment Mode
- Product
- Quantity
- Region
- Unit Price

## Dashboard Features
- Total Sales
- Total Orders
- Total Quantity
- Average Unit Price
- Total Customers
- Region-wise Sales
- Product-wise Sales
- Sales Trend by Order Date
- Payment Mode-wise Sales
- Discount-wise Sales
- Interactive slicers for Region, Payment Mode, and Order Date

## Key Insights
- West region generated the highest sales.
- Smartphone generated the highest product sales.
- Cash payment mode generated the highest sales.
- 10% discount category generated the highest sales.
